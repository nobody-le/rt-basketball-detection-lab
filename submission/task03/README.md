# 任务三 · 输入尺寸与阈值对比

用预训练 `yolo11n.pt` 在 CPU 上跑仓库的 14 张验证图，比较三组设置。匹配标准为 IoU ≥ 0.50，只保留 `sports ball` 类。

| 组 | 输入尺寸 | 置信度阈值 |
|---|---:|---:|
| A | 640 | 0.10 |
| B | 320 | 0.10 |
| C | 320 | 0.25 |

## 统计表

| 组 | 有球匹配 | 边缘球匹配 | 无球误报 |
|---|---:|---:|---:|
| A · 640 / 0.10 | **4 / 12** | **1 / 2** | **0 / 2** |
| B · 320 / 0.10 | **3 / 12** | **0 / 2** | **0 / 2** |
| C · 320 / 0.25 | **2 / 12** | **0 / 2** | **0 / 2** |

验证集构成为 12 张有球帧（其中 2 张边缘球）、2 张无球帧。三组都没有无球误报。

## 第 25、275 帧的完整球变化

| 帧 | A · 640 / 0.10 | B · 320 / 0.10 | C · 320 / 0.25 |
|---|---|---|---|
| 25 | 未检出 | 命中，conf 0.3165，IoU 0.9562 | 命中，conf 0.3165，IoU 0.9562 |
| 275 | 命中，conf 0.2703，IoU 0.9729 | 命中，conf 0.1561，IoU 0.9588 | 未检出 |

`frame-025-compare.png`：A 漏掉完整球，B/C 命中。

`frame-275-compare.png`：A/B 命中，C 因 0.25 阈值过滤掉 conf 0.1561 的框。

## 边缘球与无球帧检查

|---:|---|---|---|---|
| 145 | edge | 命中，conf 0.1247，IoU 0.7699 | 未检出 | 未检出 |
| 150 | edge | 未检出 | 未检出 | 未检出 |
| 180 | empty | 0 框 | 0 框 | 0 框 |
| 200 | empty | 0 框 | 0 框 | 0 框 |

## 选型结论

**不采用 320；选 640，阈值 0.10。**

依据：

- 完整球：640/0.10 命中 4/12，320 最好也只有 3/12。
- 边缘球：640/0.10 命中 1/2；320 两档均为 0/2。B 已把阈值降到 0.10，两张边缘帧仍无检测。
- 无球帧：三组均为 0/2 误报，320 没有减少误报的收益。
- 320 唯一的可见收益是第 25 帧这类完整球更稳，但代价是第 275 帧在 0.25 下丢失、边缘球全丢。

在 640 下补跑 0.25 作阈值对照：

| 设置 | 有球匹配 | 边缘球匹配 | 无球误报 |
|---|---:|---:|---:|
| 640 / 0.10 | **4 / 12** | **1 / 2** | 0 / 2 |
| 640 / 0.25 | 3 / 12 | 0 / 2 | 0 / 2 |

0.10 比 0.25 多命中 1 张完整球和 1 张边缘球（第 145 帧，conf 0.1247，IoU 0.7699），误报仍为 0/2，因此 0.10 在本验证集上严格更优。

最终配置：**`imgsz=640`、`conf=0.10`、CPU、仅 `sports ball`**。

适用边界：验证集只有 14 帧（2 张边缘、2 张无球），结论只代表这组教学样例。若必须用 320 省算力，应先对边缘帧扩边/填充再推理，而不是继续降阈值。
