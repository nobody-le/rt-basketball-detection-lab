# 任务四 · 全量微调与冻结前 10 层对比

从同一个预训练 `yolo11n.pt` 出发，在仓库 33 张训练图上各训练 5 轮；用 14 张验证图在 `imgsz=640`、`conf=0.25`、IoU ≥ 0.50 的共同口径下评测。

## 训练配置

| 项 | 全量微调 | 冻结前 10 层 |
|---|---|---|
| 权重 | `yolo11n.pt` | `yolo11n.pt` |
| freeze | 无 | 10（第 0–9 层） |
| 可训练参数 | 2,624,064 / 2,624,080 | 1,508,320 / 2,624,080 |
| 冻结参数 | 16（DFL） | 1,115,760（42.5%） |
| epochs | 5 | 5 |
| imgsz | 416 | 416 |
| batch | 8 | 8 |
| device | CPU | CPU |
| optimizer | AdamW | AdamW |
| lr0 | 0.001 | 0.001 |
| seed / deterministic | 42 / true | 42 / true |
| mosaic / mixup / scale | 0.0 / 0.0 / 0.20 | 0.0 / 0.0 / 0.20 |
| workers / plots | 0 / false | 0 / false |

数据：`data.yaml`，train 33 张、val 14 张、test 8 张。完整参数见 `configs.json` 与各自的 `args.yaml`。

## 冻结范围与数据分工

Ultralytics 的 `freeze=10` 对应 `model.0`–`model.9`：前 10 层（早期 backbone 的 Conv、C3k2、SPPF，共 1,115,744 个参数）设为 `requires_grad=False`，不会被优化器更新；这些层内的 BatchNorm 在训练时固定为 eval，running mean/var 也不更新。冻结层仍参与前向，继续提供特征。

其余 1,508,320 个参数（C2PSA、neck、检测头等）正常反向传播更新。另有 `.dfl.conv.weight` 的 16 个参数被 Ultralytics 固定冻结，即使全量微调也不更新，因此全量组的可训练数是 2,624,064，而不是总参数 2,624,080。

- 训练集 33 张：唯一参与梯度更新的数据，两组都用它训练 5 轮。
- 验证集 14 张：不参与梯度更新；训练时每轮计算 val loss / mAP 并据此选 `best.pt`，训练后再在 640/0.25/IoU 0.50 下用于两组比较。
- 因此 `best.pt` 与最终比较共用同一批 14 张图，这是同分布口径，不是独立泛化估计；8 张 test 未参与。

## 结论

- 两组在共同口径下完全并列：0/12 有球匹配、0/2 边缘球、0/2 误报，没有可区分的精度差异。
- 冻结前 10 层把可训练参数降到 1,508,336（57.5%），第 5 轮累计训练时间从 8.47 s 降到 4.23 s（约 −50%），但两组都尚未形成可用的检测头。
- 5 轮不足以让重置后的检测头收敛；该结果不能替代预训练权重。任务三中预训练 640/0.10 仍有 4/12 有球命中、1/2 边缘球命中，因此实际回看应继续用预训练权重，而不是这两组微调权重。
- 若后续必须微调且算力受限，冻结前 10 层是更省算力的起点，但需要更多轮次重新验证，不能据本次 5 轮结果判断精度优劣。

## 下一步：证据强度与选择

共同评测（640/0.25/IoU 0.50）两组都是 0/12、0/2、0/2，处于指标地板：两组都没有任何检测框，0 与 0 不能区分精度。因此仅凭这张表不能宣布任一组更好。

训练内验证损失提供了弱信号（第 5 轮）：

| 指标 | full | freeze10 |
|---|---|---|
| 第 5 轮 val box / cls / dfl | 1.482 / 4.628 / 1.758 | **1.037** / 4.663 / **1.156** |
| 第 5 轮 train box / cls / dfl | 1.775 / 1.585 / 0.788 | 1.768 / **1.521** / 0.802 |
| 累计训练时间 | 8.47 s | **4.23 s** |
| 可训练参数 | 2,624,064 | **1,508,320** |

freeze10 的 val box/dfl 更低，训练时间约为一半，说明它至少没有比全量更差，且更稳。因此如果继续微调，下一步值得先尝试 **freeze10**：延长轮次，同时保留 full 作为对照，并在未参与选模的 8 张 test 上做一次独立评测。

但现有证据仍不足：只有 5 轮、33 张训练图，检测头重置后两组 val mAP 全为 0；14 张 val 同时用于选 `best.pt` 和最终比较；边缘/无球各只有 2 张，单帧变化就会让比例跳动 50%。在这些限制下，“freeze10 更好”只是值得验证的假设，不是已证结论。
